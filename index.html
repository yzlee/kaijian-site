从素材到成片，每一步都为访谈重做过

本地转写 · 词级时间戳

faster-whisper 跑在你自己的机器上，默认 large-v3；有 NVIDIA 显卡自动走 GPU。词级时间戳意味着一句话可以只留半句。

逐句评级 + 理由

四档评级配一句人话说明，可按档筛选。理由是确定性生成的，不是模型随口一说。

钩子按组确认

一个钩子＝主句 + 垫话 + 后续句，整组一起确认。你确认的钩子排在成片最前，正片里还可以再出现一次做回扣。

问答块是最小单位

结构先于价值：先切出「问 + 答」，再决定哪些块进片。段内守逻辑，段间抢留存。

语气词自动掐掉

嗯 / 啊 / 呃 自动标上删除线。切缝只吃静音不吃字，接缝处 20ms 淡入淡出防爆音。

访谈构图硬约束

每个画面必须有人物，头部不能被大面积裁掉。16:9 / 9:16 / 1:1 之间换比例时自动顶部对齐，导出前硬校验。

帧对齐导出

每段吸到帧格，音视频同一时长，字幕与音乐跟着重映射。默认原色原声直通——不替你调色、不替你美化人声。

字幕四个入口都能改

转写稿里改、时间线字幕轨上改、整句纠正、半句覆盖——粗剪之后照样改得动。

越剪越准

你每一次「留这句、删那句」都进口味档案，下一期作为方法层规则注入 AI 的判断。规则要连续两期被印证才生效，失效自动降级。

中文剪辑执行稿

导出一份 PDF：每句带时间码和说话人，附标题建议与关键词。交给助理也能照着剪。

说话人分离与人工终审

主持人 / 嘉宾自动区分，现场第三人也认得出。你手动改过的标注是终审，重新分析不会被模型改回去。

对标样片可以学

拖进来一条你想学的片子，它会拆出切换节奏、每句时长、响度基线，作为方法注入下一次分析。

五步，你只在第 4 步做决定

  1. 1

    导入素材

    多机位一起拖进来。相机的 LRV 低清代理自动识别用于预览，不用转码；HEVC 播不动会提示一键生成 540p 代理。

  2. 2

    本地转写

    句级 + 词级时间戳落盘，说话人分离，语气词标记。这一步不联网。

  3. 3

    AI 通读全文

    逐句评级、抽钩子候选、拟标题、排出问答块骨架，并写清剪辑思路。断点可续跑。

  4. 4

    拍板与对话调整

    确认钩子组、勾选句子；右侧直接说「再紧凑 20 秒」「把讲定价的部分加进来」，时间线实时改。

  5. 5

    导出成片

    从原片按帧精确切割拼接，可选 9:16 竖版。同时导出剪辑执行稿 PDF 与字幕。

      你的素材去哪了

      1. 访谈原片、代理、成片：只在你自己的硬盘上。没有上传，没有云端转码。
      2. 转写默认在本地跑，音频也不出机器。选「云端转写」模式时，把音频（不是视频）传给你自己填的 whisper 接口（OpenAI / Groq / 中转站），随时可切回本地。

      4. 只有你主动拖进来的「对标参考片」会抽帧交给视觉模型拆解节奏。不用这个功能就完全不发生。

      常见问题

      能不能不装软件，直接在网页上用？

      界面本来就是网页——但引擎（转写、ffmpeg 切割、导出）跑在你自己的机器上，所以还是得装。 做成纯云端要把几十 GB 的 4K 原片传上去，按国内的上行带宽，光上传就比剪辑本身久，服务器算力也要有人付钱。 眼下更现实的中间路线是「云端只处理文字」：上传音频出一份带时间码的剪辑执行稿，你拿回本地套用——如果你需要，我可以做。

      要花多少钱？

      工具本身免费。AI 部分用你自己的 Key，按你和服务商之间的计费走；不填 Key 也能用转写和手动剪辑，只是没有评级和自动成片。

      必须有显卡吗？

      不是必须。本地转写有 NVIDIA 显卡走 GPU 快得多，没有则回落 CPU；或者直接选云端转写模式——连本地引擎都不用装，无显卡的机器反而更快。导出同理，检测到硬件编码器就用。

      我的访谈内容会被拿去训练吗？

      视频不出你的硬盘。文字转写发给的是你自己配置的模型服务商，是否用于训练取决于你和他们的协议（Claude、OpenAI 的 API 通道默认都不拿来训练）。这一层的选择权在你手上。

      支持多长的素材？

      按小时级的访谈设计。举个有前提的数字：一期 43 分钟的访谈转写出 1217 句、约 1 万字，逐句都能点选。

      转写要等多久？

      另一条 22.6 分钟的素材在带 GPU 的机器上跑了 136 秒，约 10 倍实时。这两个数字来自不同素材、不同机器，别当成同一场测试。

      导出的是什么？

      横版成片（可选 9:16 竖版）、字幕文件、中文剪辑执行稿 PDF。默认原色原声直通：不替你调色，也不替你「美化」人声，需要时才开增强链。

      支持英文访谈吗？

      转写引擎本身多语言，界面和剪辑方法论目前是按中文访谈打磨的。英文能跑，但钩子判据、标题规则这些还没在英文素材上校准过。

      数字口径说明

      • 「1217 句 / 约 1 万字」来自一期 43 分钟的访谈。
      • 「约 10 倍实时 / 136 秒」来自另一条 22.6 分钟的素材，NVIDIA 显卡。与上一条不是同一场测试。
      • 音频增强链的指标（背景 +8dB / 人声 −0.3dB）是开启增强链时的门槛；默认路径是原声直通，不跑这条链。
