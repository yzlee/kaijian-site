钩子不是随机生成，是闯过了四层判断

开头三秒决定留存。每条钩子候选都要过完这四关，才会出现在你面前。

01

高传播特征学习

从你投喂的对标样片里持续学习高传播内容的开场模式与表达特征——学方法，不搬文案。

02

原片语境校验

钩子必须能被后文兑现，不断章取义——开头写的支票，正片必须认账。

03

多维评分排序

信息缺口、自足性、反差、前置度逐维打分并给出理由；分数只用来排序，不替你判决。

04

反馈权重更新

你的接受、拒绝、改写与排序都沉淀成规则，规则要连续两期被印证才生效——越剪越准。

高传播特征 + 原片语境兑现 + 多维评分。钩子按组确认：主句、垫话、后续句整组一起走，确认的排最前，正片里还能回扣一次。

内容方案生成

多个选题角度与开场版本，各带结构、支撑片段与高能段落。回答的不只是「剪什么」，还有为什么这样剪。

自动成片编排

语义切段 / 片段筛选 / 顺序重排 / 切点生成，直接落成带字幕的完整时间线。访谈按问答块吸附，不会剪出答非所问。

字幕与时间线联动

词级时间码转写（一句话可只留半句）、说话人分离与语义校对、嗯啊呃一键清理；改字幕同步作用于片段，音画不错位。

      常见问题

      能不能不装软件，直接在网页上用？

      界面本来就是网页——但引擎（转写、ffmpeg 切割、导出）跑在你自己的机器上，所以还是得装。 做成纯云端要把几十 GB 的 4K 原片传上去，按国内的上行带宽，光上传就比剪辑本身久，服务器算力也要有人付钱。 眼下更现实的中间路线是「云端只处理文字」：上传音频出一份带时间码的剪辑执行稿，你拿回本地套用——如果你需要，我可以做。

      要花多少钱？

      工具本身免费。AI 部分用你自己的 Key，按你和服务商之间的计费走；不填 Key 也能用转写和手动剪辑，只是没有评级和自动成片。

      必须有显卡吗？

      不是必须。本地转写有 NVIDIA 显卡走 GPU 快得多，没有则回落 CPU；或者直接选云端转写模式——连本地引擎都不用装，无显卡的机器反而更快。导出同理，检测到硬件编码器就用。

      我的访谈内容会被拿去训练吗？

      视频不出你的硬盘。文字转写发给的是你自己配置的模型服务商，是否用于训练取决于你和他们的协议（Claude、OpenAI 的 API 通道默认都不拿来训练）。这一层的选择权在你手上。

      支持多长的素材？转写要等多久？

      按小时级的长内容设计（访谈、播客、课程、会议）。两个有前提的数字：一期 43 分钟的访谈转写出 1217 句、约 1 万字，逐句都能点选；另一条 22.6 分钟的素材在带 GPU 的机器上 136 秒转完，约 10 倍实时——两条来自不同素材、不同机器，别当成同一场测试。

      导出的是什么？

      横版成片（可选 9:16 竖版）、字幕文件、中文剪辑执行稿 PDF。默认原色原声直通：不替你调色，也不替你「美化」人声，需要时才开增强链。

      支持英文访谈吗？

      转写引擎本身多语言，界面和剪辑方法论目前是按中文访谈打磨的。英文能跑，但钩子判据、标题规则这些还没在英文素材上校准过。

      数字口径说明

      • 「589 句 → 47 条钩子候选 → 12 组内容方案」是一次实测样本，结果随素材变化。
      • 「1217 句 / 约 1 万字」来自一期 43 分钟的访谈。
